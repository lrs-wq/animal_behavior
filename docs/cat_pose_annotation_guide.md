# 猫姿态 17 关键点统一标注规则

版本：v1.0（2026-07-13）

## 1. 任务边界

本数据集训练的是“单猫裁剪图上的 17 点姿态”。一张图片只对应一只猫、一个姿态实例。当前裁剪流程把整张裁剪图作为姿态模型的输入，因此标签中的 `cat` 框暂时固定为全图：

```text
0 0.5 0.5 1.0 1.0
```

该框只表示裁剪输入范围，不表示精确猫框；不得用本数据集的 box mAP 判断猫检测效果。如果以后要在完整场景中直接运行姿态模型，必须另建数据集并重新标注紧贴猫可见区域的检测框。

## 2. 固定关键点顺序

左右一律按“猫自身的左、右”，不是画面左、右。水平翻转时使用：

```text
[0, 2, 1, 3, 4, 8, 9, 10, 5, 6, 7, 14, 15, 16, 11, 12, 13]
```

| ID | 名称 | 唯一落点定义 |
|---:|---|---|
| 0 | 鼻尖 | 鼻镜中心最前端，不标嘴或下巴 |
| 1 | 左眼 | 猫左眼可见眼裂中心；闭眼时取眼裂中心 |
| 2 | 右眼 | 猫右眼可见眼裂中心；闭眼时取眼裂中心 |
| 3 | 颈背 | 颈部与躯干连接处的背侧中线，约为两肩之间略靠前的位置 |
| 4 | 尾根 | 尾巴与骨盆连接处，不是尾尖，也不是臀部轮廓中心 |
| 5 | 左前肩 | 左前肢肩关节中心 |
| 6 | 左前肘 | 左前肢肘关节中心 |
| 7 | 左前爪 | 左前爪掌部中心；落地时取接触区域中心 |
| 8 | 右前肩 | 右前肢肩关节中心 |
| 9 | 右前肘 | 右前肢肘关节中心 |
| 10 | 右前爪 | 右前爪掌部中心；落地时取接触区域中心 |
| 11 | 左后髋 | 左后肢髋关节中心，不标身体外轮廓最高点 |
| 12 | 左后膝 | 左后肢膝关节（膝/膝盖），不要误标为跗关节 |
| 13 | 左后爪 | 左后爪掌部中心；落地时取接触区域中心 |
| 14 | 右后髋 | 右后肢髋关节中心，不标身体外轮廓最高点 |
| 15 | 右后膝 | 右后肢膝关节（膝/膝盖），不要误标为跗关节 |
| 16 | 右后爪 | 右后爪掌部中心；落地时取接触区域中心 |

## 3. 可见性编码

每个点固定写成 `x y v`，共 17 组：

- `v=2`：点清楚可见，能够直接定位。
- `v=1`：点被毛发、肢体或物体遮挡，但能根据相邻肢体可靠推定。坐标仍必须标在推定关节位置。
- `v=0`：点在画面外、完全不可判断或该部位未出现。坐标必须写成 `0 0 0`。

禁止以下做法：

- 可见的点因为“难标”而直接省略。
- 对完全不可判断或画面外的点猜测坐标。
- 用 `0 0 1` 或 `0 0 2` 表示点存在。
- 同一个关键点重复标注多次。

## 4. 完整性规则

看到什么就标什么，不按固定数量凑点：

1. 头部可见时，鼻尖和可见眼睛必须标注。
2. 颈背可见时必须标 3；尾巴与骨盆连接处可判断时必须标 4。
3. 一条腿可判断到哪一级，就连续标到哪一级；例如肩、肘、爪均可见时不得只标爪。
4. 侧身只显示一侧肢体时，另一侧若完全不可判断则为 `0 0 0`；若被身体遮挡但位置可可靠推定则标 `v=1`。
5. 正面、背面和俯视仍按猫自身左右标注。拿不准左右时进入复核队列，不得按画面左右猜测。

## 5. 主训练集准入规则

17 点按四个区域统计：头部 `0–2`、躯干轴 `3–4`、前肢 `5–10`、后肢 `11–16`。

进入主训练/验证/测试集的样本必须同时满足：

- 标签严格为 `5 + 17×3 = 56` 列，坐标和可见性合法。
- 至少 5 个有效点（`v>0`）。
- 至少覆盖 3 个身体区域。
- 所有画面内清楚可见的点均已标注。
- 无重复点、左右错误或明显错位。

不足 5 点或不足 3 个区域的头部特写、严重遮挡图不删除，进入 `review_queue`/辅助集；补标通过后才能回到主数据集。验证集和测试集不得包含尚未复核的稀疏标签。

## 6. 质检顺序

每张图按以下顺序检查：

1. 确认猫自身左右方向。
2. 检查头部 0–2。
3. 检查颈背和尾根 3–4，尤其确认 4 不是尾尖。
4. 分别沿左前、右前、左后、右后肢检查“近端关节 → 中间关节 → 爪”。
5. 检查 `v=0/1/2` 是否符合定义。
6. 检查同名点是否重复、明显可见点是否漏标。

自动审计只能发现格式、稀疏度和区域覆盖问题，不能可靠判断猫自身左右或关节落点；这些项目必须人工复核。
