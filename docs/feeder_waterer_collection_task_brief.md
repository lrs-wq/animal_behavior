# 喂食器与喂水器家庭视频采集任务简版

版本：1.0  
日期：2026-07-30

## 1. 任务目标

采集不同家庭中喂食器和喂水器区域的视频，用于提升猫咪检测、姿态估计以及吃饭、饮水行为识别模型的泛化能力。

重点要求：

1. 尽可能覆盖不同家具、猫玩具、地面、光照、摄像机角度和设备外形；
2. 每段核心视频中必须有猫咪出现，出现几秒也可以；
3. 必须同时采集真实吃饭、真实饮水和猫出现但未吃喝的场景；
4. 同一家庭的视频必须跨天采集。

## 2. 采集数量

| 用途 | 家庭数 | 每户数量 | 合计 |
| --- | ---: | ---: | ---: |
| 开发数据 | 100 户 | 10 段 | 1000 段 |
| 独立测试 | 50 户 | 10 段 | 500 段 |

测试家庭必须是未参与训练、调参和难例筛选的新家庭。

## 3. 每户10段怎么拍

| 内容 | 数量 |
| --- | ---: |
| 喂食器 | 5 段 |
| 喂水器 | 5 段 |
| 白天 | 7 段 |
| 夜间或红外 | 3 段 |
| 真实吃饭 | 3 段 |
| 真实饮水 | 3 段 |
| 猫出现但没有吃喝 | 4 段 |

拍摄时间要求：

- 覆盖至少 4 天，最好 5～7 天；
- 白天视频至少分布在 3 天；
- 夜间视频至少来自 2 个夜晚；
- 夜间必须是真实夜间、低照度或红外画面，不能用软件把白天视频调暗；
- 同一段长视频不能重复切出时间重叠的片段充数。

## 4. 每段视频必须满足

- 时长 55～65 秒；
- 分辨率不低于 720p；
- 帧率不低于 15 FPS；
- 喂食器或喂水器主要区域清晰可见；
- 视频中必须有猫咪出现，允许只出现数秒；
- 猫咪不能全程只剩极小、严重遮挡或无法辨认的局部；
- 文件能够完整播放，无损坏、长时间黑屏或画面冻结；
- 不要添加检测框、水印或后期滤镜，提交原始画面；
- 每户至少 3 段应包含猫出现前或离开后不少于 15 秒的空场景。

建议每户 10 段中猫咪累计清晰可见时间不少于 60 秒；猫只出现不足 2 秒的视频不要超过 1 段。

## 5. 优先覆盖的环境

采集人员应主动选择差异较大的家庭，不要集中在相似户型和相同设备品牌。

优先覆盖：

- 客厅、厨房、餐厅、走廊、阳台、卧室和猫笼区；
- 木地板、瓷砖、地毯、泡沫垫和石材；
- 沙发、桌椅、柜子、床、窗帘、纸箱和收纳袋；
- 猫爬架、抓板、隧道、球、逗猫棒和毛绒玩具；
- 毛毯、塑料袋、猫图案、电视画面、阴影和镜面反光；
- 不同品牌、颜色、尺寸和材质的自动或重力式喂食器；
- 循环饮水机、重力饮水器、透明水箱和金属反光水碗；
- 高、中、低机位，俯视、侧视、近景、远景和广角画面；
- 黑猫、白猫、橘猫、狸花猫、长毛猫、幼猫、大体型猫和多猫家庭。

建议至少 20 户为多猫家庭，避免设备、摄像机或猫咪外观过度集中。

## 6. 配套空背景

核心 10 段仍要求每段有猫，但建议每户额外提供 15～20 分钟同机位无猫画面，不计入核心视频数量。

空背景主要用于处理以下误检：

- 毛绒玩具和毛毯被识别成猫；
- 家具、猫砂或食物被识别成猫；
- 反光饮水器、阴影、窗帘和电视画面触发误报；
- 夜间红外切换、自动曝光和画面噪声导致误报。

## 7. 文件命名

文件名不要包含姓名、地址、电话号码或设备序列号。

推荐格式：

```text
家庭ID_采集日序号_设备_光照_序号.mp4
```

示例：

```text
H0001_D01_feeder_day_01.mp4
H0001_D03_waterer_night_02.mp4
```

建议目录：

```text
H0001/
  videos/
  metadata.csv
  consent/
```

## 8. 每段需要登记的信息

```text
household_id
file_name
capture_date
day_or_night
feeder_or_waterer
eat_drink_or_noninteraction
cat_count
room_type
camera_angle
resolution
fps
duration_seconds
privacy_checked
```

采集日期可以只保留相对日序号，例如 `D01`、`D02`，不需要在文件名中保存家庭地址或人员信息。

## 9. 隐私要求

- 必须取得家庭授权；
- 镜头尽量只覆盖喂食器或喂水器区域；
- 原则上不得出现人物、门牌、家庭照片和电脑或手机屏幕；
- 不需要声音，上传前应移除音轨；
- 不需要 GPS、设备序列号和其他无关元数据；
- 家庭联系方式与视频数据分开保存；
- 参与家庭提出撤回时，必须能够找到并删除其视频、抽帧和标签。

## 10. 提交前检查清单

- [ ] 家庭 ID 正确且已经匿名化；
- [ ] 每户核心视频数量符合要求；
- [ ] 喂食器和喂水器数量符合要求；
- [ ] 白天 7 段、夜间 3 段；
- [ ] 包含真实吃饭 3 段、真实饮水 3 段；
- [ ] 每段均有猫咪出现；
- [ ] 视频跨至少 4 天；
- [ ] 文件能够完整播放；
- [ ] 无重复或时间重叠片段；
- [ ] 已完成隐私检查；
- [ ] metadata 信息填写完整。

## 11. 测试验收

- 测试使用 50 个完全独立的新家庭；
- 同一家庭、猫咪、摄像机和设备不得同时进入开发集和测试集；
- 冻结模型和阈值后再开始正式测试；
- 当前内部验收门槛为至少 40/50 家庭通过；
- 40/50 代表样本通过率 80%，其单侧 95% 置信下界约为 68.44%；
- 该门槛仅用于当前阶段内部验收，不能解释为已经统计证明覆盖 90% 以上家庭。
