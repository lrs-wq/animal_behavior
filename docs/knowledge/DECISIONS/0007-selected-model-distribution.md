## 决策

按用户明确要求，发布分支允许 `models/weights/manifest.json` 中的四个训练权重副本，
使用逐文件 Git 白名单、完整 SHA-256 和选型依据。其他训练产物仍保持忽略。
生产权重和注册表继续使用既有受控路径；本地例子通过独立 `models.github*.yaml` 加载仓库副本。

## 依据

当前生产组合已经登记哈希并运行。v9 三组训练中，现行检测器 mAP50 最高，100 epoch
候选 mAP50-95 最高；两者同时分发。分类器按框架 fitness 选模，姿态选择已注册的
真实机位适配第二阶段 epoch 140。具体数值与评测边界见 `docs/model_weights.md`。

## 约束

复制不改变权重字节，不推送数据集或其他 checkpoint，不取消 allowed_roots 与哈希检查，
不自动推广候选到生产。Codeup 仍是默认 origin，发布分支与 GitHub main 接收同一提交。
知识库仅记录模型身份、角色、路径与规则，不能包含权重二进制。
