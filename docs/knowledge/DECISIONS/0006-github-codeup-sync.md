# 0006 — Codeup 主跟踪与 GitHub 源码发布

日期：2026-09-30  
状态：已接受

## 决策

保留阿里云 `origin` 和既有分支 upstream，GitHub 使用独立 `github` remote。
在隔离同步分支汇总已核对的当前代码，先保存到 Codeup，再发布同一提交到 GitHub `main`。
当前运行服务仍从 `/root/Eating_behavior` 读取代码；同步工作树不作为部署目录。

源码仓库包含代码、文档以及 `docs/demo/` 的逐文件演示媒体白名单。
其他媒体、模型权重、训练数据、运行状态和凭据保留在仓库外；忽略规则覆盖图片和视频。

## 依据与影响

用户要求同步最新源码、提供方便演示的少量素材，并继续在阿里云跟踪代码。
独立 remote 和发布分支保留两端相同提交，现有生产分支与本地工作区继续按原方式跟踪。
上传前检查待提交文件与历史对象；未来增加媒体需要人工核对并更新明确白名单。

操作命令及范围见 `docs/source_sync.md`。此决策不触发服务重启或自动模型推广。
